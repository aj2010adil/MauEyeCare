# 🏥 MauEyeCare - Doctor's Quick Start Guide (Windows Local Setup)

Welcome to **MauEyeCare Hospital Management System**! Follow this quick step-by-step guide to run the app on your local Windows PC or laptop.

---

## ⚡ Quick 1-Click Launch (Easiest Way)

If Python is already installed on your computer, starting the system takes just 1 double-click:

1. Open the project folder `MauEyeCare`.
2. **Double-click** on the file named **`Run_MauEyeCare.bat`**.
3. A black window will open and automatically setup everything for you.
4. Your default internet browser (Chrome, Edge, or Firefox) will open automatically to:
   👉 **`http://localhost:8501`**

> ⚠️ **Important Note:** Keep the black command window open while you are using the app. Minimizing it is fine! To close the app when finished, simply close the black window.

---

## 🛠️ First-Time Setup (If Python is not installed)

If double-clicking `Run_MauEyeCare.bat` says Python is missing, follow these 2 simple steps:

### Step 1: Install Python
1. Download Python for Windows from the official site: [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. Open the downloaded installer file.
3. 🔴 **CRITICAL STEP:** At the bottom of the first setup screen, check the box that says:
   ✅ **`Add python.exe to PATH`** (or *Add Python to environment variables*).
4. Click **Install Now** and wait for it to complete.

### Step 2: Launch the App
1. Go back to your `MauEyeCare` folder.
2. Double-click **`Run_MauEyeCare.bat`**.
3. It will automatically download all required libraries and start the app in your browser!

---

## 📌 Optional: Create a Desktop Shortcut for 1-Click Access

To start MauEyeCare directly from your Windows Desktop:
1. Right-click on **`Run_MauEyeCare.bat`** in the `MauEyeCare` folder.
2. Click **Show more options** (or Send to) ➔ **Send to** ➔ **Desktop (create shortcut)**.
3. On your Desktop, rename the new shortcut to **`MauEyeCare Hospital System`**.
4. Double-click that Desktop icon anytime to launch!

---

## 💡 Troubleshooting & Tips

- **Browser didn't open automatically?**
  Open Google Chrome or Microsoft Edge and type `http://localhost:8501` into the address bar.
- **Port 8501 is busy?**
  Close any existing black command windows that might still be running MauEyeCare in the background, then double-click `Run_MauEyeCare.bat` again.
- **Need to sync Google Sheets patient records?**
  Click the **`🔄 Sync Google Sheets`** button in the top left sidebar inside the web app.
